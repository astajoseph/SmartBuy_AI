SmartBuy AI — System Architecture
Indian-market purchase intelligence · price history every 3 h in the cloud · vendor pages only on demand · deterministic decisions, Gemini explains
User
Web browser (desktop / mobile)
Asks: buy now or wait? which vendor? EMI? reviews?
Frontend
Next.js 15 · TypeScript · Tailwind · Recharts
Pages
Dashboard · Product detail & price chart · Purchase advisor + chat · Vendors & EMI · Reviews · Sale intelligence · Settings · Admin
Data labels
Every figure tagged Observed · Source-stated · Estimate · Forecast · Unknown · Vendor page
No secrets
Only the public API URL; preferences in browser storage; admin token typed per session
Backend API — FastAPI · Python 3.12
API routers /docs
products · prices · history · forecast · seasonality · vendor-comparison · reviews · recommendations · assistant/chat · events · admin
Price statistics
History stats, period changes, percentile of today's price, data-quality flags; gaps > 30 days treated as unknown
Forecasting & seasonality
Baselines chosen by chronological backtest, 80 % intervals, target probability (Brier-checked), Indian sale-event windows, weekday/month tests
Review analysis
Aspect sentiment (texture, skin reaction, value, delivery …), product vs seller reviews kept separate, small-sample warnings
Recommendation engine
Deterministic, unit-tested policy → BUY_NOW · WAIT · MONITOR · BUY_IF_TARGET_REACHED · COMPARE_VENDORS · INSUFFICIENT_DATA
Finance
EMI (reducing / flat / zero-interest), fees + GST, No-Cost-EMI check, bank & cashback offer value, ranking by objective
Vendor service on demand
Cache first (price 1 h · EMI/offers 12 h · reviews 24 h–7 d); adapters amazon_in · myntra · nykaa · generic; blocked pages never bypassed
LLM assistant
Rule-based intent → engine → evidence; untrusted web text fenced; ₹ numeric guard; template fallback; read-only
Security layer
SSRF-safe fetcher (allow-list, public-IP DNS check, IP pinning, redirect re-check, size/time limits) · robots.txt · per-domain & per-client rate limits · admin token · Supabase JWT · log secret redaction
GitHub Actions · cloud
smartbuy-collect every 3 h
cron 17 */3 * * * · scheduler --once
Collector worker + headless Chromium (Playwright); advisory locks, retries, job log; then forecasts & alerts
smartbuy-tests
CI on every push: 150 backend tests (Postgres service) + frontend build
External sources & services
pricehistory.app price history

Vendor sites only when a user asks

Google Gemini 2.5 Flash explains only
Receives structured evidence, writes the explanation; cannot change the action or numbers (provider swappable: LLM_PROVIDER=gemini | none)
